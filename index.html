Download for Windows

Windows 10 or 11 · needs Claude Code on your PATH · free, MIT

  1. Tabs that tell you who needs you

    Every tab is a session of its own: its own shell, its own Claude Code, its own directory. A dot says whether Claude is working, has finished, or is waiting for a permission.

    Ctrl+Shift+T new tab · windows, tabs and chats come back on launch

  2. A real shell, with Claude already in it

    PowerShell on ConPTY, not an emulation. Anthra runs claude in the directory you opened, and when Claude Code exits the shell stays, so you can restart it or do something else.

    Anthra never touches your Claude Code configuration

  3. Context and cost, live

    Context against the auto-compact threshold, the token breakdown with cache hits, session and daily cost with a per-turn curve and history, the git status of the repository and your recent chats, one click from resuming.

    Ctrl+B hides the panel when you want the full width

  4. Look away. Anthra calls you back.

    A Windows toast and a taskbar badge when Claude waits for a permission or finishes a turn, only for tabs you are not looking at. Click it and you land on that tab.

    Throttled per tab, so a long session never turns into noise

Updates itself, then gets out of the way.

The installed build downloads new versions in the background and installs them when you quit. Your windows, tabs and chats reopen afterwards, with a What’s new window listing what changed.

  1. +30 sChecks after launchand again every 6 hours
  2. backgroundDownloads quietlyno prompt while you work
  3. on quitInstallsor now, with Restart to update in the tab bar
  4. next launchEverything is backwindows, tabs, chats and What’s new

Portable and Scoop installs show a button instead. Preferences → Updates turns the check off.

Install in one line.

Per-user, no admin rights. Pick the channel you already use; every one of them keeps Anthra up to date.

Anthra is not code-signed yet, so SmartScreen warns once about the installer download. winget, Scoop and Anthra’s own updates don’t go through SmartScreen.

Straight answers.

Why does SmartScreen warn me?

Anthra is not code-signed yet, and SmartScreen warns about unsigned downloads it has not seen often. To check a download, compare its SHA-512 with the sha512 in that release’s latest.yml: 

[Convert]::ToBase64String([Security.Cryptography.SHA512]::Create().ComputeHash([IO.File]::ReadAllBytes("$PWD\Anthra-Setup-<version>-x64.exe")))
Are the costs what I will be billed?

No, they are estimates from a local rate table. On a subscription they are the API-equivalent cost of what you used.

Does it change my Claude Code setup?

No. Anthra never writes to Claude Code’s configuration. It starts claude in a real PowerShell and reads the transcripts Claude Code already writes.

How do I remove Anthra completely?

Uninstall it from Windows Settings (or winget uninstall iFrosty-tech.Anthra, scoop uninstall anthra), then delete %APPDATA%\Anthra.

I updated from 0.6 and nothing happened.

Versions 0.6 and earlier have no updater, so that one update has to be done by hand. From 0.7 on, Anthra updates itself.
